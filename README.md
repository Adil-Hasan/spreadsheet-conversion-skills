# Spreadsheet Conversion Skills

Standalone installable Codex skills extracted from the MCQ Sheet maker and CQ to Sheet instruction packs.

## Install

With the Vercel Skills CLI, install one or both skills from this repository:

```sh
npx skills add Adil-Hasan/spreadsheet-conversion-skills --skill mcq-sheet-maker --skill cq-to-sheet
```

Install either skill separately by omitting the other `--skill` option. The source plugin instruction references are kept beside each `SKILL.md` so each skill retains its detailed rules, templates, and examples.

## Included skills

- `mcq-sheet-maker` — MCQ document extraction and spreadsheet formatting.
- `cq-to-sheet` — Creative Question extraction and spreadsheet formatting.
